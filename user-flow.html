02 · Feature Access

フェーズ別・機能アクセス一覧

lifecycle_phase と機能フラグ（canUserAccessFeature）の組み合わせで全機能のアクセス権を制御。

機能 initial_onboarding free_retention paid
キャリア診断作成 ✓ ✓ ✓
日記記入 ✓ ✓ ✓
持ち味レポート閲覧 ✓ ✓ ✓
AIフィードバック ✓ — ✓
内省チャット ✓ — ✓
持ち味レポート再生成 — — ✓
人生史編集 — — ✓
WCM 編集 — — ✓
キャリア軸診断 — — ✓
マイルストーン管理 — — ✓
initial_onboarding フェーズは AIフィードバック・内省チャットが利用可能。体験フックとして設計されており、無料継続後はロックすることで有料転換を促す。
03 · Subscription States

サブスクリプション状態遷移

plan カラムと subscription 系カラムの組み合わせで getEffectivePlan() が状態を判定する。

effectivePlan lifecyclePhase 発生条件 機能アクセス
free initial_onboarding 初回登録〜持ち味レポート生成前 体験フック機能を含む限定開放
free free_retention Paywall で「無料で続ける」を選択後 診断・日記・レポート閲覧のみ
subscribed paid Stripe 決済完了・plan = 'subscribed' 全機能
session paid sessionEndsAt が未来 全機能（期限付き）
grace paid 解約後 gracePeriodEndsAt が未来（最大30日） 全機能（猶予期間中）
trial 状態は廃止済み。trialDaysLeft は deprecated。usePlan() hook が SWR で /api/user をキャッシュし、lifecyclePhase と effectivePlan を返す。
